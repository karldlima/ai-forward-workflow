# Practices

Four practices keep agent output reliable, reduce regressions and maintain high standards of code quality/architecture/security.

| Practice | What it covers |
| --- | --- |
| [Prompt engineering](prompt-engineering.md) | Curating, refining and saving inputs so the LLM produces reliable outputs |
| [Context engineering](context-engineering.md) | Curating the dynamic data the agent uses, maximising information per token |
| [Harness configuration](harness-configuration.md) | The execution environment, tools and guardrails around the model |
| [Verification loops](verification-loops.md) | The checks the agent runs before submitting a PR |
